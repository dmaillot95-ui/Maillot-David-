EXECUTION MODEL
- Each farm receives the same immutable checkpoint plus one specialized mission.
- Each farm may launch a 20-role polymorphic matrix.
- Farms run concurrently when GitHub Actions quotas permit.
- Same model family is NOT an independent proof source.
- FARM COUNT != INTELLIGENCE.
- Successful jobs are counted separately from successful external AI inference calls.
- All farm outputs are UNREVIEWED until master-hub audit.

MASTER MERGE PROTOCOL
1. verify run status and artifacts;
2. count real successful external AI calls;
3. classify by model family and role;
4. reject unsupported closure claims;
5. rederive key mathematics independently;
6. compare cross-farm claims;
7. keep only mutually compatible audited lemmas;
8. expose contradictions and unknowns;
9. define exactly one NEXTLOCK;
10. CYCLES CLOSED only after an arbitrary-N proof survives cross-farm audit.
