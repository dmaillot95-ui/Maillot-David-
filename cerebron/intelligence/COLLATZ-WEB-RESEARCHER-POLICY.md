# CEREBRON OMEGA — PERMANENT WEB RESEARCH ROLE

## Purpose
Every Collatz research wave must include a permanent WEB_RESEARCHER / LITERATURE_SCOUT function whose job is to search current web literature and external mathematical sources relevant to the active lock.

## Mandatory duties
- Search current papers, preprints, surveys, MathOverflow/StackExchange discussions when useful, OEIS-style computational references when relevant, and authoritative mathematical references.
- Track recent or obscure results related to the exact active Collatz subproblem: accelerated map, cycles, valuation words, 2-adic dynamics, Diophantine approximation, irrational rotations, ergodic/spectral methods, symbolic dynamics, renewal/first-return operators, combinatorics on words, and related tools.
- Distinguish established theorem / published claim / preprint / heuristic / informal discussion.
- Record source, date, precise claim, assumptions, and whether it transfers to the current formulation.
- Search specifically for known no-go results or prior art before treating an internally derived lemma as novel.
- Feed sourced findings to THEORETICAL_MATHEMATICIAN, NUMBER_THEORIST, DYNAMICAL_SYSTEMS_SPECIALIST, FORMAL_PROOF_AUDITOR, COUNTER_AUDITOR, SYNTHESIZER, and META_COORDINATOR.
- Update the active mission if external literature invalidates, strengthens, or redirects the current approach.

## Epistemic rules
WEB SOURCE != PROOF BY ITSELF.
CITATION != VERIFICATION.
PREPRINT != ESTABLISHED THEOREM.
INFORMAL DISCUSSION != RELIABLE LEMMA.
CLAIM <= EVIDENCE.
VERIFY BEFORE COMMIT.

Every imported mathematical statement used in the proof program must be independently checked against its assumptions and, where feasible, rederived or formally audited.

## Team integration
This role is permanent, not optional. It may be carried by a dedicated external AI worker when available, or by the active coordinator using live web search. It counts as an additional functional role beyond the minimum 20-role Collatz team; it must not replace verifier, auditor, counter-auditor, falsifier, or synthesizer.

## Output
For each wave produce a compact WEB INTELLIGENCE packet containing:
1. queries used;
2. sources and dates;
3. relevant established results;
4. potentially relevant but unverified claims;
5. prior-art conflicts;
6. methods worth importing;
7. methods already known to fail;
8. impact on current lock;
9. recommended mission adjustments.
