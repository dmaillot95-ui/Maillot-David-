# CÉRÉBRON ΑΩ — C45 CAMPAIGN 2000

## Fixed subject
Increase the verified capability-acquisition performance of CÉRÉBRON under reality control.

## Frozen baseline
The baseline for every rung is the same C43/C44 architecture state before this campaign rung begins. Results from a larger rung may be compared with smaller rungs, but are not allowed to silently redefine the baseline.

## Scale ladder
10 -> 20 -> 50 -> 100 -> 250 -> 500 -> 1000 -> 2000 work units.

A work unit is a distinct, recorded contribution to the same target. It is NOT automatically an AI agent, model call, or independent evidence path.

## One human interaction rule
Each user command SUITE authorizes exactly the next rung. The rung may contain many internal work units, but must return one consolidated report.

## Measurement
For every rung record:
- number of planned units
- number of completed units
- unique useful outputs
- duplicates/redundancies
- contradictions found
- candidates kept/merged/killed
- new executable mechanisms
- new tests
- verified gains if any
- regressions
- unresolved residuals
- complexity added
- evidence level
- whether any capability claim is actually justified

## Core metric
Verified Capability Gain / Campaign Cost (VCGC-C)

Supporting metrics:
- useful_unit_rate
- redundancy_rate
- contradiction_resolution_rate
- executable_output_rate
- verification_rate
- transfer_candidate_rate
- residual_reduction

## Rules
REALITY > COHERENCE
CLAIM <= EVIDENCE
SIMPLE FIRST
COMPLEX ONLY WHEN SIMPLE FAILS
SAME BASELINE FOR EVERY RUNG
BATCH WHEN INDEPENDENT
SEQUENCE WHEN DEPENDENT
NO WORK UNIT COUNTS AS AN AGENT UNLESS AN ACTUAL AGENT/MODEL EXECUTION OCCURS
NO DOCUMENTATION-ONLY CHANGE COUNTS AS VERIFIED CAPABILITY GAIN

## Campaign question
How much useful, verified capability-acquisition work can CÉRÉBRON compress into one human interaction before marginal quality falls or complexity stops paying rent?
